# Air–Ground Channel Modeling — Source Code

This repository contains source code for air–ground channel simulation, geometry-based path hypotheses, multipath estimation, and learning-based channel prediction.

## Contents

- `ckm_sim/`: propagation, sounding, and parameter-estimation modules
- `support/`: geometric and physical utilities
- `scripts/`: training, evaluation, and analysis code
- `configs/`: code configuration files
- `tests/`: implementation tests
- `requirements.txt`: Python dependencies

## Setup

Use a compatible Python environment and install dependencies:

```bash
python -m pip install -r requirements.txt
```

Some commands require external channel data, scene assets, or model checkpoints **not distributed in this repository**. This is a code-only snapshot, not a standalone end-to-end dataset release.

## Repository scope

Unpublished manuscripts, LaTeX sources, figures, presentation files, experimental reports, raw or processed measurements, and trained checkpoints are deliberately excluded. Do not commit private project links or research drafts.
